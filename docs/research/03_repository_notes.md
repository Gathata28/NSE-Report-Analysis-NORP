# Multi-issuer report repository notes

## Source
- Webpage title: Kenya Financial Documents - Nairobi Securities Exchange
- URL: https://africanfinancials.com/kenya-listed-company-documents/
- Accessed: 2026-08-27

## Observed taxonomy
The page presents a searchable repository of Kenya financial documents and exposes filters for sector, document type, year, period, and company. Document types include Abridged Reports, Annual Reports, Circulars, Interim Reports, Presentations, and Prospectus. Period filters include FY, HY, Q1, Q2, Q3, and Q4. The year filter spans 1996 through 2026.

## Research use
This repository is a useful broad discovery layer for current and historical Kenyan listed-company documents, especially where issuer IR archives are incomplete. Its entries still need to be traced to and verified against issuer, exchange, regulator, or document-level provenance where possible. The final index will label repository-hosted links separately from issuer-hosted links and will not imply that a repository link is the original issuer URL unless confirmed.

## Caveat
The page is dynamically filtered. Search results are not all present in the initial HTML, so the filters or underlying request endpoints must be inspected to enumerate the full corpus efficiently.
