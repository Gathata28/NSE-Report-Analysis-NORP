

## Follow-up historical-source search — 2026-08-27

Searches for an authoritative all-time or delisted-issuer list found official NSE pages for [Our Story](https://www.nse.co.ke/our-story/) and [Corporate Actions](https://www.nse.co.ke/corporate-actions/), but no single complete historical/delisted issuer table in the returned sources. The NSE Our Story page contains historical listing events such as Umeme Holdings’ cross-listing on 14 December 2012; it is useful for event evidence but not a complete former-issuer universe.

Official CMA Resource Center annual-report results surfaced issuer-specific report archives for Equity Bank 2025, Olympia 2017–2018, Stanlib Fahari I-REIT 2017, Standard Chartered Bank 2021, Housing Finance 2018, and Kenya Commercial Bank 2006. These are report sources, not evidence that an issuer is currently listed, delisted, or suspended. Do not infer status from search-result absence. Continue using explicit NSE/CMA notices, corporate actions, and issuer records for status fields.
